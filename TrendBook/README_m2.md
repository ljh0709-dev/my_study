# TrendBook 기획 회고 및 향후 작업 계획

## 프로젝트 개요

**TrendBook(트렌드북)**은 실시간 이슈와 도서 데이터를 연결해 사용자에게 맞춤형 도서를 추천하고, 독후감 작성과 AI 이미지 생성을 함께 지원하는 도서 큐레이션 플랫폼이다.

현재는 실제 구현보다 프로젝트 기획을 중심으로 진행했다. 서비스의 방향성, 요구사항, 데이터 수집 방법, 화면 구성, 주요 기능 흐름을 먼저 정리하며 구현 전에 전체 구조를 잡는 데 집중했다.

## 현재까지 진행한 내용

- 서비스명과 핵심 컨셉 정의
- 주요 기능 도출
  - 도서 검색 및 목록 조회
  - 회원가입, 로그인, 프로필 관리
  - 도서 상세 정보 조회
  - 독후감 게시글 작성
  - 독후감 기반 AI 이미지 생성
  - 향후 실시간 이슈 기반 도서 추천
- 기능적 요구사항과 비기능적 요구사항 정리
- 알라딘 API를 중심으로 사용할 데이터 탐색
- ERD, Use Case Diagram, 화면 설계 방향 검토
- 페이지 구성 초안 정리
  - 홈
  - 게시판
  - 프로필
  - 도서 목록
  - 게시글 상세 및 작성 화면

## 기획 단계에서 느낀 점

이전 프로젝트에서는 기능을 먼저 구현하면서 필요한 구조를 그때그때 추가하는 방식에 가까웠다. 하지만 이번에는 구현 전에 요구사항, 데이터, 화면, 사용자 흐름을 먼저 정리해보니 프로젝트를 훨씬 넓게 바라보게 되었다.

특히 서비스가 단순히 "도서 목록을 보여주는 사이트"에 머물지 않으려면 어떤 데이터가 필요하고, 사용자가 어떤 흐름으로 서비스를 이용해야 하는지 먼저 생각해야 한다는 점을 느꼈다. 도서 API를 가져오는 것 자체보다, 그 데이터를 어떤 기준으로 저장하고 어떤 화면에서 어떤 맥락으로 보여줄지가 더 중요했다.

pjt04에서 배운 Django MTV 패턴과 CRUD 흐름은 이번 프로젝트의 기본 뼈대가 될 수 있다. 도서, 게시글, 댓글, 프로필 같은 데이터를 모델로 정의하고, Form을 통해 입력값을 검증한 뒤, view와 template으로 사용자에게 보여주는 흐름은 그대로 활용할 수 있다.

pjt05에서 배운 인증과 접근 제한도 이번 프로젝트에서 중요하다. 독후감 작성, 프로필 수정, AI 이미지 생성 같은 기능은 로그인한 사용자와 연결되어야 하므로 `@login_required`, 사용자별 데이터 조회, 작성자 권한 확인 같은 패턴을 다시 적용해야 한다.

pjt06에서 경험한 외부 API와 AI 연동은 이번 프로젝트의 차별화 기능에 직접 연결된다. 알라딘 API로 도서 데이터를 가져오고, 사용자가 작성한 독후감을 AI 이미지 생성 기능과 연결하려면 외부 서비스 응답을 어떻게 처리하고 실패 상황을 어떻게 안내할지 미리 설계해야 한다.

기획을 하면서 가장 크게 느낀 점은 "기능 목록을 많이 적는 것"보다 "핵심 기능이 서로 자연스럽게 이어지는 흐름을 만드는 것"이 더 중요하다는 것이다. TrendBook의 핵심은 도서 검색, 독후감 작성, AI 이미지 생성, 추천 기능이 따로 존재하는 것이 아니라 하나의 독서 경험으로 연결되는 데 있다.

## 이번 프로젝트에 적용할 학습 내용

### Django 기본 구조

- 앱별 역할을 명확히 분리한다.
- 모델, 폼, 뷰, 템플릿의 책임을 구분한다.
- URL namespace를 사용해 페이지 이동 구조를 안정적으로 관리한다.
- 반복되는 비즈니스 로직은 view에 몰아넣지 않고 별도 함수나 서비스 모듈로 분리한다.

### 사용자 인증

- 회원가입, 로그인, 로그아웃 기능을 구현한다.
- 독후감 작성과 프로필 수정은 로그인 사용자만 접근할 수 있게 한다.
- 게시글 수정 및 삭제는 작성자만 가능하도록 권한을 확인한다.
- 사용자별 독후감 목록과 생성 이미지 목록을 프로필에서 확인할 수 있게 한다.

### 외부 API 활용

- 알라딘 API를 활용해 도서 목록과 상세 정보를 조회한다.
- API 응답에서 필요한 필드만 정리해 서비스에서 사용할 데이터 형태로 변환한다.
- API 호출 실패, 검색 결과 없음, 응답 지연 같은 예외 상황을 사용자에게 안내한다.

### AI 기능 연동

- 독후감 내용을 기반으로 이미지 생성 프롬프트를 구성한다.
- 생성된 이미지를 게시글 또는 사용자 기록과 연결해 저장하는 방식을 검토한다.
- AI 응답이 늦거나 실패하는 경우를 고려해 로딩 상태와 오류 메시지를 설계한다.

## 마무리

이번 기획 단계는 구현을 바로 시작하지 않고 서비스의 목적과 흐름을 먼저 정리했다는 점에서 의미가 있었다. 이전 프로젝트에서 배운 Django의 기본 구조, 인증, 외부 API, AI 연동 경험을 이번 프로젝트에 어떻게 녹일 수 있을지 생각해볼 수 있었다.
